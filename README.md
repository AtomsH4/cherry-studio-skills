# Cherry Studio Skills

Public AI agent skills for [Cherry Studio](https://github.com/CherryHQ/cherry-studio).

## Skills

| Skill | Purpose |
| --- | --- |
| [`design-cherry-lifecycle`](skills/design-cherry-lifecycle/) | Decide whether a Cherry Studio main-process capability should use Lifecycle, check for lifecycle over-design, and review a proposed lifecycle shape. |

## Install with Codex

Install the skill from:

<https://github.com/AtomsH4/cherry-studio-skills/tree/main/skills/design-cherry-lifecycle>

The skill is read-only: it analyzes and recommends. It does not modify Cherry Studio code or generate an executable implementation plan.
